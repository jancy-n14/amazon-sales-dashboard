# Amazon Sales Dashboard

## 📊 Project Overview

This project presents an interactive Amazon Sales Dashboard developed using Microsoft Excel.

The dashboard analyzes Amazon sales data to provide insights into sales performance, order quantity, customer ratings, delivery time, and state-wise sales distribution.

## 🎯 Project Objective

The objective of this project is to transform raw sales data into meaningful business insights using Excel-based data analysis, Pivot Tables, and data visualization.

## 🛠️ Tools & Techniques

- Microsoft Excel
- Data Cleaning
- Pivot Tables
- Pivot Charts
- Data Analysis
- Data Visualization
- Dashboard Design

## 📈 Dashboard Features

The dashboard provides insights into:

- Total Sales
- Total Quantity Sold
- Average Customer Rating
- Average Delivery Time
- State-wise Sales
- Sales performance
- Order-level data analysis

## 📁 Workbook Structure

The Excel workbook contains three main sheets:

| Sheet | Description |
|---|---|
| **Data** | Raw Amazon sales/order-level data |
| **Pivot** | Pivot Tables used for analysis |
| **Dashboard** | Visual dashboard and charts |
